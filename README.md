# 🚀 Node.js Demo App with CI/CD Pipeline

A simple Node.js Express application automated with a **GitHub Actions CI/CD Pipeline** that automatically tests, builds, and pushes the Docker container image to **DockerHub** on every push to the `main` branch.

---

## 🛠️ Tech Stack & Tools
* **Runtime:** Node.js (v18)
* **Framework:** Express.js
* **Containerization:** Docker
* **CI/CD Automation:** GitHub Actions
* **Container Registry:** DockerHub
